### Self-Evolution Loop

```python
while True:
    # 1. Generate code
    code = generate_with_current_prompts(task)
    
    # 2. Score quality
    quality = autonomous_scorer.score(code)
    
    # 3. Learn patterns
    if quality > threshold:
        patterns.learn(code)
    
    # 4. Evolve prompts
    prompts = genetic_algorithm.evolve(
        population=prompts,
        fitness=quality_scores
    )
    
    # 5. Raise bar
    threshold = adaptive_adjust(quality)
    
    # 6. Repeat with BETTER prompts
    # → Next iteration generates BETTER code
```

1. **Functionality** (0.25): AST parsing, executable code

4. **Documentation** (0.15): Docstrings, comments, clarity
5. **Novelty** (0.15): Uniqueness vs known patterns
6. **Integration** (0.15): Cross-references, modularity
