**Sources**: `Impossible Prompting` playbook, `System_Instructions.txt` Python rigor framework, and `CODEX_AUTONOMOUS_FRAMEWORK_v4.yaml.md` orchestration model.

This protocol fuses the cognitive vertigo prompts with Codex's autonomous agent stack and the disciplined Python engineering rules. Use it as a turnkey script for producing, critiquing, and refining code artifacts while staying aligned with PEP 8, architectural readability, and metacognitive safeguards.

## 2. Execution Macro-Loop

1. **Initialize ethical guardrails** (`No Harm`, `No Bullshit`, `Make Real Things`). Confirm the artifact to be produced and measurable acceptance checks.
2. **Run Impossible Prompt Stack**: combine temporal fragmentation, paradox integration, and dimensional debugging for every significant decision. Record prompts + answers in the uncertainty ledger.
3. **Apply System Constraints Continuously**: after each reasoning pivot, run a compliance ping (PEP 8 scan, type annotation audit, cyclomatic complexity estimation).
4. **Synthesis Pulse**: leverage the dialectical engine — articulate thesis/antithesis for the chosen design, then merge into a synthesis that obeys constraints and documented unknowns.
5. **Metacognitive Retrospective**: before handing off, perform `introspection → coherence validation → reasoning transparency → ethical self-audit`. Capture deltas in the propagation log.

## 3. Prompt Templates by Workflow

### Specification Drafting
- **Setup**: "Using only what we *do not* understand about the domain, design a requirements suite that a future maintainer can evolve."  
- **Checklist**: Guarantee type-hinted signatures, docstring placeholders (72 char width), and explicit test vectors for edge uncertainties.

### Implementation Sprint
- **Setup**: "Implement the feature as a duet between deterministic and improvisational mindsets. Every 15 lines, restate the design from a new dimensional lens (2D structure, 4D runtime, emotional, network)."  
- **Checklist**: Ensure functions remain ≤50 lines; refactor when nesting >2 levels; maintain in-flight complexity notes.

### Debugging / Incident Response
- **Setup**: "Explain the failure to a medieval peasant, a senior SRE, and your 20-year future self. Force them to agree on a remediation plan."  
- **Checklist**: Generate targeted tests for the least understood areas, document risk mitigations, log paradoxes encountered and how they were resolved.

### Code Review & Handoff
- **Setup**: "Pair with the future maintainer who already stabilized the adjacent subsystem. What invariants must remain sacred?"  
- **Checklist**: Validate lint/test automation hooks, confirm coverage >80%, finalize a handoff brief referencing the uncertainty ledger.

---

## 4. Instrumentation & Tooling Hooks

- **Static Enforcement**: integrate `flake8`/`ruff` for PEP 8 enforcement and cyclomatic complexity checks. Automate failing the build if constraints violated.
- **Dynamic Coverage**: maintain pytest suites that surface coverage <80% as blocking. Attach coverage badge updates to the propagation manager.
- **Decision Trace Logging**: store prompt-response cycles in `logs/impossible_codex/`. Include timestamp, agent role, prompt archetype, and outcome summary.

---

## 5. Hand-Off Ritual

1. Publish the uncertainty ledger, rationale changelog, and review transcript.
2. Document remaining paradoxes or unresolved contradictions with mitigation steps.
3. Archive all artifacts alongside the updated repository overview entry for discoverability.

This protocol operationalizes the Impossible Prompting mindset within Codex’s autonomous pipeline, ensuring every creative leap is balanced by disciplined engineering rigor.
